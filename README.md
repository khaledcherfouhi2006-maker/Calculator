# 🧮 Simple Calculator

A clean, minimalist, and responsive web-based calculator designed with iOS-inspired circular buttons, built using vanilla **HTML5**, **CSS3**, and **JavaScript**.

🔗 **Live Demo:** [khaledcherfouhi2006-maker.github.io/Calculator](https://khaledcherfouhi2006-maker.github.io/Calculator/)

---

## ✨ Features

- **Basic Arithmetic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **Dynamic Expression Input:** Sequential entry of digits and decimal numbers directly onto the digital display screen[cite: 36, 37].
- **Calculation Evaluation:** Evaluates expressions upon clicking the equals (`=`) button[cite: 36, 37].
- **Error Handling:** Catches invalid syntax and displays a clear `ERROR` state rather than breaking the application[cite: 36].
- **Clear Display:** Resets input instantly with a dedicated clear (`C`) button[cite: 36, 37].
- **Modern Dark Interface:** Dark theme UI styled with custom CSS Grid layout, hover transitions, and active tactile feedback states[cite: 34, 35].

---

## 🛠️ Built With

- **HTML5:** Semantic keypad structure, container layout, and readonly display input[cite: 37].
- **CSS3:** CSS Grid (`repeat(4, 1fr)`), circular buttons, HSL color palettes, and hover/active animations[cite: 35].
- **JavaScript (ES6):** Input concatenations, display state management, and calculation execution[cite: 36].
- **GitHub Pages:** Static site hosting and deployment.
